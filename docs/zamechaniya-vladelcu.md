по общему спреду. Фактически это порог по спреду ноги акций **при нулевом спреде ноги ZN**, с учётом
мёртвой зоны 0,25 п.п. Проверка формул движка: `(0,25 + 0,8381 − 0,062) / 0,823 = 1,2468`.

## C. Содержательные пробелы маршрута Е

**C1. Нет стрессовой цифры для Е, сопоставимой с 2,36× маршрута Ф.** §7 v1.5.3.1 даёт для Ф запас
8,9× в норме и 2,36× в композитном стрессе. Для Е в §8 такой цифры нет вообще. Расчёт по конвенции
самого документа (день −20,4%, требования растут):

| поддерживающее требование после удара | запас Е |
|---|---|
| 25% (норма) | 1,49× |
| 30% | 1,24× → срабатывает О-3-Е |
| 35% | 1,06× → на грани маржин-колла |

Реалистичный исход — не ликвидация, а принудительное сокращение до L=1 в худший момент. Цифру надо
внести в §8 явно.

**C2. Критерий О-3-Е при штатных допущениях сработать не может.** Порог 1,40, модельное отношение
`1/(0,25 × плечо)`; при максимальном плече закрытия 2,0452 отношение 1,956, и это же минимум по всему
окну. Критерий оживает только если IBKR поднимет поддерживающее требование выше **34,9%**. То есть вся
защита Е держится на одном непроверенном числе. Стоит либо признать это в тексте, либо привязать О-3-Е
к фактическому требованию с самого начала (live margin preview этого не заменяет — он разовый).

**C3. Маржинальный след Е нигде не сопоставлен с Ф.** При плече 2,0: Ф — ~11,2% капитала, Е — 50%
(25% × 2,0). Разница структурная и в документе не проговорена.

**C4. Дивидендный drag 0,20%/год занижен.** По ряду Шиллера из пакета средняя дивидендная доходность
S&P 500 за 2003–2026 = 1,67% (медиана 1,85%); при ирландском удержании 15% выходит **0,25%/год**.
Занижение около 0,05 п.п. в пользу Е. Либо поднять норматив, либо обосновать 0,20 отдельно.

**C5. Пилот экономику маршрута Е не подтверждает.** Подтверждено расчётом: на 1 млн CAGR 9,79% против
9,89% на 10 млн, займ 0,622 против 0,534 п.п. — лестница ставок IBKR делает пилотный масштаб дороже.
Из §7 не следует, что с этим делать. Нужна явная оговорка: результат пилота на Е не переносится на
боевой масштаб.

свободный выбор. Проверено расчётом; повышение плеча дополнительно роняет доход на единицу качки
(0,84 → 0,81 → 0,76 при 2,0 / 2,2 / 2,5×) и поднимает оборот (42 → 49 → 61 сессия в год).
