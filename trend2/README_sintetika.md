# Дневная синтетика ADD-FUT (обновление 19.08.2026)

Заменяет прежнюю месячную версию. По просьбе заказчика найден публичный
дневной источник для акционной ноги, идущий заметно раньше 1979 года.

## Источники (все — сырые, публичные, независимые)

- **Акции**: Kenneth French Data Library (Tuck School, Дартмут) — дневные
  факторы Mkt-RF и RF с 1926-07-01, построены на CRSP (весь рынок NYSE/AMEX/
  NASDAQ, дивиденды учтены). `Mkt-RF + RF` = дневная ПОЛНАЯ доходность рынка
  США — общепринятый академический прокси S&P 500. Файл сохранён в
  `trend2/data_sintetiki/F-F_Research_Data_Factors_daily.csv`.
- **Облигация**: дневная доходность 10-летних казначейских (DGS10, FRED,
  `r33build/data/dgs10.csv`, уже был в репозитории), переведённая в полную
  доходность через дюрацию Маколея купонной облигации по номиналу.

`us-market-daily-1885-2025.csv` по-прежнему не используется — там чужой
готовый расчёт (Swap Rate, Total Real Return), а не сырые данные.

## Что изменилось

Дневная гранулярность вместо месячной ступеньки — движок теперь видит
внутримесячные просадки на синтетическом участке, а не только доходность
месяца целиком.

## Итог, окно 1979-01-02…2026-08-07 (было / стало)

|                    | месячная синтетика | дневная синтетика |
|--------------------|--------------------|--------------------|
| счёт, CAGR         | 14.39%             | 14.08%             |
| счёт, просадка     | −15.0%             | **−16.7%**         |
| часть 1 (ES+ZN), CAGR | 14.43%          | 14.12%             |
| часть 1, просадка  | −23.0%             | **−31.3%**         |

Дно счёта и части 1 теперь приходится на **26.10.1987** — то есть синтетика
поймала обвал 19 октября 1987 года (дно с лагом на исполнение позиции),
который протокол прямо называет отсутствующим во фьючерсной истории и
главной причиной, почему короткое окно «льстит вдвое». Просадка части 1
(−31.3%) теперь в одном пункте от протокольной ADD-FUT-одной по всей
64-летней истории (−32.9% в разделе 3 — там правило SMA12, здесь база+SMA12
комбинация, не строго то же измерение, но порядок величины и сам факт
поимки провала 1987 года совпадают).

Числа по-прежнему НЕ подгонялись под протокол (правило 1) — совпадение
порядка величины и даты дна получено независимо, это сверочный сигнал,
а не цель построения.
