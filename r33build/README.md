# ADD-FUT v1.5.3.1 — пакет воспроизводимости
Тип симуляции: прокси-P&L с целочисленным отображением во фьючерсные контракты и модельной стоимостью ролла. Контрактное состояние — целочисленное между сделками; сайзинг сделок по данным предыдущей сессии (T+1).
Нормативный документ — только ADD-FUT-v1_5_3_1.pdf (порядок приоритета — его §10).

## Проверка (одна команда из корня)
    pip install -r requirements.txt
    python run_all_v13.py
Конвейер четырёх уровней: (0) MANIFEST до расчётов; (1) пять окон §3 с допусками + сравнение сформированных NAV с эталонами data/nav_v13_*.csv: даты точно, значения с относительной точностью 1e-12 (допуск машинного шума одного ULP при переносе между средами; содержательная порча превышает допуск на ~10 порядков); (2) депрессия; (3) точное сравнение сигналов модели с data/signals_monthly.csv и О-2 целыми эталонами (175 смен; макс 9; ≥8 — 13; >12 — 0). Ожидание: десять строк [PASS] и итоговая, код 0. Порча ЛЮБОГО файла данных, эталонного NAV или одиночного сигнала обязана давать код 1 — самотесты см. ниже.

## Самотесты (выполняются на копии пакета)
1. Инвертировать один сигнал в data/signals_monthly.csv → код 1 (уровень 3).
2. Изменить одно значение в data/nav_v13_modern.csv → код 1 (уровни 0 и 1).
3. Изменить один байт любого файла из MANIFEST → код 1 (уровень 0).

## Структура
- run_all_v13.py, sim_v13.py, depr_v13.py — контрольный конвейер (данные ищутся в ./data).
- data/ — входные ряды и эталоны (NAV, сигналы); хэши — MANIFEST.txt.
- code/ — исследовательские скрипты этапов (flat-режим, для проверки не нужны).
- archive/ — исторические документы с титульной страницей «применению не подлежит».

## Ставка и данные
